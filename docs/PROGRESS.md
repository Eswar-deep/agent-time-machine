# Project status

The debugger supports recording, checkpoint restoration, manual forks, tool replay,
and model-proposed repairs for the bundled scenarios. The Playground compares a
scripted parser run with a live Meta run using the same starting files and evaluator.

The [validation report](VALIDATION.md) separates observed provider runs from automated
tests. The [architecture guide](ARCHITECTURE.md) describes the execution boundary,
and [Git history](https://github.com/Eswar-deep/agent-time-machine/commits/main)
records implementation changes.
